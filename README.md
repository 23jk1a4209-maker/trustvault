\## 🛡️ Project Overview

\*\*TrustVault\*\* is a secure, role-based document management platform engineered using \*\*Python Flask\*\* and \*\*SQLite\*\*. It resolves the challenge of unauthorized document access and data tampering by strictly enforcing Role-Based Access Control (RBAC) and providing an immutable audit trail for complete accountability.



\---



\## 🚀 Key Features

1\. \*\*Cybersecurity Design Theme:\*\* Polished high-contrast dark palette (Black `#0B0F0D` and Emerald Green `#10B981`).

2\. \*\*Role-Based Access Control (RBAC):\*\*

&#x20;  - \*\*👑 Owner:\*\* Full administrative authority (Upload, Download, Search, and Permanent Deletion).

&#x20;  - \*\*👁️ Viewer:\*\* Restricted access (Read \& Download only; Upload and Delete actions are blocked).

3\. \*\*Private File Vault:\*\* Uploaded confidential assets are stored safely on the filesystem with metadata tracked in SQLite.

4\. \*\*Verifiable Accountability (Audit Logs):\*\* Every login, upload, download, and deletion event is recorded with UTC timestamps and security status (`SUCCESS` / `BLOCKED`).

5\. \*\*Instant Document Search:\*\* Live keyword and classification filtering for rapid retrieval.
